# 粤仔：条件规则与真实范例

基础 profile v1 + 制作精修规则 v2，研究日期 2026-10-19。
基础规则与冻结 profile 保留其原始证据边界；二轮追加的 P 规则属于制作指导，尚不是同一份
profile 的机器参数约束。通过 `style inspect` 表示基础证据有效，仍需完成原生精修与参考对比。

首轮全库 70 条/89.4 分钟做格式与实帧盘点；
其中 12 条/11.94 分钟用于提炼，4 条/4.52 分钟为独立留出检验，均完成真实 ASR。
单条科技发布会舞台片作为离群内容保留盘点、排除风格训练。

| 规则 | 何时使用 | 执行动作与例外 |
| --- | --- | --- |
| R01 一次相遇一个故事 | 同一组人有完整互动 | 保留问题、身份/语境、答复与结果；删空走和无关串场 |
| R02 真高光预告 | 后文金句独立可理解 | 约 1～3 秒原声预告，硬切回最短语境；温暖问候可直接入场 |
| R03 关系构图 | 人狗共同完成互动 | 原竖屏和缩放 1 优先，保留脸、狗与动作空间 |
| R04 短句字幕 | 可辨识的现场口播 | 常见橙黄粗体、暗描边，约画面 77%～80% 高；字色存在子类 |
| R05 真实反应重音 | 实帧确有笑、惊讶或动作 | 保留反应停顿，大字服务真实重音；按二轮 P 规则安排进退和层次，温暖题材降低喜剧字密度 |
| R06 回报后收尾 | 已完成祝福、合照、爱心或包袱 | 等自然结果结束，再决定是否加短 CTA；不硬加品牌卡 |
| R07 封面分离 | 需要展示封面 | 单独保存封面，视频立即进真实内容，避免长静态片头 |
| R08 按事件定节奏 | 问答、温情、表演或短梗 | 保留必要来回和连贯动作；时长由故事决定 |

两个冷开场范例是训练 ref007 的 0.44～3.28 秒提问，接 4.4 秒职业问答；
以及 ref010 的 0.2～1.4 秒方言包袱，接 5 秒后的问候与解释。它们证明可重排原声高光，
不表示每条都要预告。ref002 的英语问候就是直接入场的反例。

ref004 的普通对话为橙黄字、笑容上方另有大字；原 720×1520 帧观察字高约 42 像素。
本机原生校准起点为 Dengb.ttf、size 10～11、y -0.54～-0.60、#FFC33D，黑描边约 0.06，
每行约 8～12 字。范围是渲染近似，具体仍看人物与狗的位置；不是反推得到的原工程参数。

留出验证支持叙事闭环、关系构图和真实反应，但 ref028 为白/浅字红描边，ref050 为较细白字
配黄色关键词，黄色粗体不能宣称跨全部作品成立。ref050 没有品牌结尾，CTA 为可选。
四条训练的 0/0.033/0.1/0.3 秒密集抽帧显示前约两帧可能是封面封装；不能当成几秒片头。

20 个完整时间戳范例、条件与例外见 [训练证据](research/evidence.json)，
具体查看范围见 [实证观察](research/observations.md)，
独立检验见 [留出结果](research/holdout.json)。机器可复用的冻结 profile 随安装副本保存，
位置由本机绑定指向；原媒体与私有云任务保留在分析工作目录。

首轮没有完整人工听过全部音轨，音乐和混音参数不作为已验证风格。
二轮确认参考的文字动画、反应图形、相纸与短时画中画具有明确落点，仅用普通大字近似仍有
实质差距。原样资源是否可用、是否已完成替代与渲染，需要在新片中逐项说明。
没有历史传播数据，“更有传播潜力”只代表选题判断，不等于测得爆款概率。

## 二轮追加：制作精修

用户对首批“对白拼接 + 有色字幕”成片给出 15 分反馈，说明基础 profile 没有覆盖成片的
反应层、视觉层次和声音设计。该反馈是当前实现差距的证据，不把某条成片的修补方案变成
所有题材必须照搬的模板。

| 规则 | 复用决策 | 证据性质 |
| --- | --- | --- |
| P01 事件脉冲 | 真实疑问、动作、笑容需要补充强调时，反应层短入短出；现场已清楚则保持干净 | ref050/045/060 密集帧确证 |
| P02 分级字幕 | 普通句、黄色关键词与造型金句各司其职 | ref050/051/060 确证；不要求全片同一字色 |
| P03 动作兑现 | 预备、倾倒、自起、解释构成完整喜剧回报 | ref050 确证；回放是新制作建议 |
| P04 反应递进 | 错峰增加文字的尺寸、数量、位置，下一句清空 | ref045/051/060 确证 |
| P05 合影回报 | 真正拍照时短相纸/白框，完成后回现场 | ref045 确证 |
| P06 情绪方向 | 夸赞时短爱心/光点，笑点时换笑字 | ref051/060 确证 |
| P07 预告回落 | 真高光预告后退回起因，再在正文兑现 | ref051/060 确证；可直接入场 |
| P08 小窗吐槽 | 短时小图形或画中画放于主体外的空处 | ref045/043 确证，具体资源非原样复刻承诺 |
| P09 声音标点 | 原声优先，事件音效和音乐按对白安排 | 新制作要求，具体参考曲目/混音尚未确证 |
| P10 去水与动态构图 | 每段有推进理由，聚焦服务视线，整片参考对比 | 当前失败反馈驱动的编辑方法；非恢复参数 |
| P11 多人回应与全片焦点 | 漫画框有助分清接话时绑定真实词钟；普通字幕足够则保持；逐段确定观看重点 | 当前多人互动反馈驱动；具体说话人与气泡指向须另有声画证据 |

新剪辑与修改成片时阅读 [成片精修](production-refinement.md)，内含每条规则的
条件、范围、例外与验收边界。二轮实际查看范围、源片与时间证据见
[二轮观察](research/second-pass.md) 和 [精简证据](research/second-pass-evidence.json)。
