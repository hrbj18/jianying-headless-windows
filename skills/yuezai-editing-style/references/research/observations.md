## 可量化视觉建议

ref004 原生 720×1520 帧在 1.366667 秒的字幕为约 42 像素高的橙黄粗字，
位于画面水平中心、纵向约 77%～80%；这是像素观察，不是反推原工程的字体名称。
多数正文每行短句，反应大字另放于人脸附近上方，避免盖住主体。

本机剪映原生校准采用 Dengb.ttf（系统独立粗体 TTF），字幕 size 约 10～11、y 约
-0.54～-0.60、颜色 #FFC33D、暗描边约 0.05～0.08、每行 8～12 字，作为近似起点。
规则允许 size 9～12、y -0.65～-0.45、每行 6～14 字；标题 size 8～22、y -0.7～0.8。
默认视频 scale=1，仅在不裁掉真人脸部或狗的关键动作时推近至不超过 1.12。
上述参数需原生预览逐条验收，不能宣称已恢复参考工程的准确字体或特效参数。

四条开头密集抽帧均在 0 和 0.033333 秒含封面，0.1 秒已为正文；约前两帧可能是平台
封面封装习惯。不要据 0 秒总览误判为需要 2～3 秒静态片头；冷开场的 1～3 秒指真实高光。
