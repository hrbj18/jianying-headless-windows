# 二轮观察：从基础规则到制作精修

2026-10-19，用户观看首批四条后反馈“像找几个对话配有色字幕，太素”，评分 15/100，要求
先把其中一条明显提升。首轮的冻结 profile 能约束源证据、选段与基础文字，但没有覆盖
参考成片的反应动画、图形组合、字幕层级、声音标点和逐事件节奏。二轮补充制作规则，
保留首轮原证据和 holdout 结论，不把一次修改的主观分数转成自动测试门槛。

## 可复用的实证

- ref050：约 1.4～2.0 秒问号由少到多；4.1～5.3 秒汗滴围绕已倒地的狗；
  7.2～8.0 秒蓝白“没事吗”；约 28.3～28.9 秒“操作失误”、30.1～31.7 秒“紧张啦”。
  普通口播是白字配黄关键词。动作全过程仍可见，图形是事件的短标点。
- ref051：43.3～45.0 秒的多尺度“哈哈哈哈”横移，45.1 秒已经清空；70.1～72.9 秒在
  “最靓丽的风景线”赞美句上铺光心。大部分普通对话仍然是现场画面与短字幕。
- ref045：3.1～3.7 秒合照出现多层倾斜白色相纸；37.9～39.5 秒“太聪明了”错峰增加
  数量、角度和尺寸；39.7 秒换单条信息，40.5 秒起短插汗滴小猫，匹配“阿姨都没有照片”。
- ref060：开头粉白“量身定做”金句与红心，随后真笑容上方大笑字；约 4.5 秒短压暗后
  回到问籍贯，19 秒后正文兑现同句。78 秒前后先黄线、后多个“哈”依次出现。
- ref043：约 1.5～3.5 秒在“大哥罩着你”的反差处有小表情窗，后文大部分镜头仍保持
  真小狗与机器狗的现场关系，不能把一处表情窗外推成全程满屏特效。

这些证据支持 P01～P08。首轮“少量大字”的执行方式过于平，二轮所见是有事件条件、层级、
进退和短时密度变化的制作。更新后的技能要求先作事件表，再决定文字、图形、构图和声音。

## 尚未确证的部分

本轮未实际听完整音轨。对各片做了 16kHz 单声道解码、20ms RMS 与音量上升瞬态检测，
它们只能显示客观电平变化。ref050 中位 RMS 约 -15.44dBFS，ref060 约 -18.09dBFS；
这两个数字不是音乐或声效身份、响度标准、混音配方的证据。

没有原工程或原直播的逐帧对应，无法把参考里的镜头变化准确分为数码推近与拍摄者移动；
也没有恢复其慢放、回放、关键帧或滤镜数值。因此声音标点、音乐闪避、明确标注的局部回放、
蒙版聚焦与数码推近，属于新片的制作建议，按当前能力验证，不能冒称参考原样参数。

P09/P10 把本次反馈变成声音、去水节奏和动态构图的工作方法。它们以作品对照检验，不以
固定轨道数、固定特效密度、导出状态或 Agent 自评分证明审美已完成。
